Preset Batching System

Pre-Set Batching System

The FluidTech Manufactured Preset Batching System are based on the time tested Vane type design. A Extremely reliable for long period of operation. Batching system for liquids is used in various process industries for batch processes. When a same quantity of liquid has to be fed in the process vessel repeatedly, You get correct quantity of liquid in very short time, reduces human dependency.

Specifications

  • Type: Positive Displacement Flowmeter
  • Size: DN-25(1") / DN-50 (2") / DN-80 (3")
  • Flowrange: 200-2400 / 1200-12000 / 2400-24000 LPH
  • MOC: Aluminum / Stainless Steel
  • Accuracy: ±0.25%
  • Operating Temperature: 80Deg. C
  • Operating Pressure: 10kg/cm²
  • End Connection: Threaded / Flange
  • Output: Pulse
  • Control Valve: Electrically Operated / Pneumatic Operated
  • Type: Single Stage Two Stage
  • Filtrations: 149 Micron

Display & Enclosure

  • Display Unit: LED Display
  • Type: Remote / Mounted
  • Inclosure: Flame Proof / Weather Proof
  • Parameter Display:
      • 6 digits Preset Batch in Liter 00000.0
      • 6 digits Delivery Batch in Liter 00000.0
      • 6 digits Flow rate in LPH 00000.0
  • Power Supply: 230 V AC / 12 V DC
